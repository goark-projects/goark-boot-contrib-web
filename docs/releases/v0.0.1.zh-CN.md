# Goark Boot Contrib Web 0.0.1

[English](https://github.com/goark-projects/goark-boot-contrib-web/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Goark Boot Contrib Web 0.0.1 是首个公开 Web Starter。它通过显式 Boot 自动配置
装配 Goark MVC、Arkarta Servlet 和嵌入式 Arkhos 容器。

精简版本历史见[变更日志](https://github.com/goark-projects/goark-boot-contrib-web/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-06)。

## :star: 新功能

- 自动配置 MVC 路由、绑定、校验、类型转换、Advice、Interceptor、Filter、CORS、
  Locale、Flash 数据和 Session Attribute。
- 提供带版本和缓存控制的静态资源与模板视图。
- 配置 Problem Details、消息转换器、WebSocket Endpoint 和共享出站 HTTP Client。
- 通过确定性的 Boot 生命周期所有权启动 Arkhos 嵌入式容器。

## :information_source: 范围

本 Starter 装配现有 Goark、Arkarta、Arkhos、Boot 和日志契约。业务 Controller
保持显式声明或由 Goark CLI 生成；运行时不扫描 classpath。

## :package: 安装

```bash
go get goark.dev/gbc-web@v0.0.1
```

要求 Go 1.26 或更高版本。在发布最终 Starter 前，应按文档化顺序发布并使用其依赖模块。

## :white_check_mark: 验证

候选版本已在 Windows 和 Debian Linux 上通过测试、vet、race、完整 Web 集成场景和
admin-minimal HTTP smoke test。

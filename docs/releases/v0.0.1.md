# Goark Boot Contrib Web 0.0.1

English | [中文](https://github.com/goark-projects/goark-boot-contrib-web/blob/v0.0.1/docs/releases/v0.0.1.zh-CN.md)

Release date: September 7, 2026

Goark Boot Contrib Web 0.0.1 is the first public Web Starter. It assembles
Goark MVC, Arkarta Servlet, and the embedded Arkhos container through explicit
Boot auto-configuration.

See the [changelog](https://github.com/goark-projects/goark-boot-contrib-web/blob/v0.0.1/CHANGELOG.md#001---2026-09-07)
for the concise version history.

## :star: New Features

- Auto-configure MVC routing, binding, validation, conversion, advice,
  interceptors, filters, CORS, locales, flash data, and session attributes.
- Serve static resources and template views with versioning and cache controls.
- Configure Problem Details, message converters, WebSocket endpoints, and a
  shared outbound HTTP client.
- Start the Arkhos embedded container through deterministic Boot lifecycle
  ownership.

## :information_source: Scope

This Starter assembles existing Goark, Arkarta, Arkhos, Boot, and logging
contracts. Business controllers remain explicit or generated by Goark CLI;
the runtime does not scan the classpath.

## :package: Installation

```bash
go get goark.dev/gbc-web@v0.0.1
```

Go 1.26 or later is required. Publish and consume the dependency modules in
the documented release order before this final Starter.

## :white_check_mark: Verification

The candidate passed tests, vet, race tests, full Web integration scenarios,
and the admin-minimal HTTP smoke test on Windows and Debian Linux.
